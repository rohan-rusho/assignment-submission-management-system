\# Assignment Submission Management System



A role-based Assignment \& Submission Management System developed for the Assistant Software Engineer recruitment project.



\## Technology Stack



\### Backend

\- ASP.NET Core Web API

\- C#

\- Entity Framework Core

\- PostgreSQL

\- JWT Authentication

\- Swagger



\### Frontend

\- Next.js

\- React

\- TypeScript

\- Tailwind CSS



\### Testing

\- xUnit
